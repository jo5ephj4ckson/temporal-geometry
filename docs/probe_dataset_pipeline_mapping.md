This document explains how entropy moves through the temporal‑geometry pipeline, starting with the probes that generate raw entropy, continuing through the datasets that store those outputs, and ending with the analysis scripts that extract temporal structure. The purpose of this file is to make the entire workflow traceable so that any reviewer can follow a result back to its origin.

Each probe in the probes directory produces one or more datasets. Hardware probes generate device‑specific entropy logs, the LED tunneling probe produces tunneling entropy streams, atmospheric scripts record entropy from Random.org, symbolic and inverted symbolic probes create manifold‑encoded sequences, PRNG drift probes capture temporal drift from the TT20 Android application, and raw temporal‑dynamics probes store unclustered entropy streams at multiple resolutions. The dataset names mirror the probe names so it is always clear which probe produced which dataset. Because the datasets are hosted on Zenodo, the filenames and structure in the Zenodo archive match the expected layout in this repository.

The analysis directory contains the scripts that operate on these datasets. Preprocessing modules prepare the raw entropy for manifold encoding. Clustering modules convert continuous entropy streams into discrete states. Transition‑matrix scripts compute movement through the manifold. Stationary‑distribution modules extract long‑term equilibrium behavior. Drift‑analysis scripts measure temporal change. Curvature modules quantify bending in entropy flow. Basin and attractor scripts identify stable and unstable regions. Flow‑mapping modules generate the directional diagrams used in the visualizations. Script names follow the same probe‑and‑dataset logic, making it possible to match a dataset to its analysis pipeline by name alone.

The pipeline works in a straight line. A probe script is run to generate entropy. That entropy is written to a dataset file whose name encodes the probe type, device or modality, and manifold resolution. The corresponding analysis scripts are then executed on that dataset, producing numerical results and figures that are saved in the visualizations directory and referenced in the paper. This probe → dataset → analysis → visualization chain is consistent across all entropy modalities and manifold resolutions used in the study.

Because the full dataset corpus is hosted on Zenodo, the same mapping applies there as well. Any researcher who downloads the Zenodo archive and runs the analysis modules in this repository will reproduce the same temporal‑geometry results. The filenames, directory structure, and pipeline relationships documented here ensure that the entire study is fully reproducible.
