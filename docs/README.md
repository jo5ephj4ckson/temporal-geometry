The docs directory serves as the central reference point for understanding how the temporal‑geometry repository is organized and how its components relate to one another. While the probes, datasets, analysis scripts, and visualizations each represent different stages of the temporal‑geometry workflow, this folder provides the documentation that connects them into a coherent, reproducible system. It explains how entropy is collected, how datasets are structured, how analysis modules operate, and how results flow from raw entropy to final scientific conclusions. Reviewers and researchers can use the documents here to navigate the project without needing to inspect every script or dataset individually.

One of the most important files in this directory is the probe‑dataset‑pipeline mapping, which traces each dataset back to the exact probe that generated it and forward to the analysis scripts that consume it. This mapping ensures full reproducibility and makes it possible to verify every figure and result in the paper. The docs directory also contains reproducibility notes, methodological explanations, and any additional supporting material that clarifies how temporal geometry is computed across symbolic, numeric, and raw manifolds. These documents complement the main README by providing deeper context and by describing the internal structure of the project in a way that is accessible to both reviewers and future researchers.

The purpose of this folder is to make the repository self‑explanatory. Anyone examining the project should be able to open the docs directory and immediately understand how the probes, datasets, analysis modules, and visualizations fit together. The documents here transform the repository from a collection of files into a fully traceable scientific workflow, ensuring that the temporal‑geometry framework can be reproduced, audited, and extended without ambiguity.
