# Supplemental Materials for Temporal Geometry

This directory contains the core section files and supplemental materials
associated with the manuscript **"Temporal Geometry: Resolution-Invariant
and Manifold-Independent Structure in Entropy Evolution."**

These files are organized as standalone components to make it easy to
track, edit, and version each section of the work.

## Core Section Files

The following files correspond to the main conceptual and mathematical
sections of the manuscript:

- **Basins_and_Attractors**  
  Basin depth, attractor strength, and their role in temporal geometry.

- **Discussion_Addendum**  
  Discussion addendum written specifically for Chaos reviewers, clarifying
  scope, methodology, and implications.

- **Formal_Definition**  
  Formal definition of temporal geometry, including manifold, encoding,
  transition structure, and invariance.

- **Mathematical_Framework**  
  Global mathematical framework: entropy sequence, manifold, transition
  matrix, drift, curvature, basins, attractors, flow, and oscillation.

- **Methods_Summary**  
  Summary of the full methodological pipeline: entropy sources,
  preprocessing, manifold construction, resolution levels, metrics,
  windowing, and validation.

- **Nonlinear_Dynamics_Comparison**  
  Comparison between temporal geometry and classical nonlinear dynamics
  tools (Takens embedding, RQA, Lyapunov exponents, Hurst/DFA, etc.).

- **Oscillation_Detection**  
  Definition and detection of oscillation in temporal metrics, including
  windowed analysis, spectral density, surrogate comparison, and null
  models.

- **Statistical_Validation**  
  Statistical validation of temporal structure using null models,
  surrogate data, spectral analysis, and distribution comparison.

- **Temporal_Curvature**  
  Definition and interpretation of temporal curvature, curvature profiles,
  and curvature classes across entropy sources.

- **Temporal_Drift**  
  Definition of temporal drift, drift hierarchy, windowing, and
  interpretation of drift magnitudes.

- **Temporal_Flow**  
  Definition of temporal flow, flow topology, windowed flow, and its role
  in temporal geometry.

## Supplemental Materials Folder

- **Supplemental_Materials/**  
  Folder reserved for additional files (figures, extended tables, raw
  outputs, or ODT/PDF aggregates) that mirror what will eventually be
  uploaded to the Chaos submission system as official supplementary
  materials.

## Usage

These files are intended to be:

- edited individually as section components,
- combined into the main manuscript and supplementary documents,
- mirrored in the Chaos submission as ODT/PDF files when the system
  requests or allows supplemental uploads.

## Reproducibility and Organization

The separation of sections into individual files is deliberate:

- it keeps each conceptual unit isolated and easy to revise,
- it allows direct mapping between GitHub content and manuscript
  sections,
- it supports future restructuring into `Supplemental_Materials` packages
  (ZIP/ODT/PDF) for journal submission.

When the Chaos submission system provides fields for supplementary
materials, the contents of these files will be exported and uploaded
directly, with this repository serving as a public, version-controlled
mirror.
