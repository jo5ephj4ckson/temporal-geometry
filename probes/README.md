The probes directory contains every entropy‑collection instrument used throughout the temporal‑geometry study. Each probe represents a distinct method of generating or capturing entropy, ranging from physical hardware devices to symbolic encodings and high‑resolution software‑based drift samplers. Together, these probes form the foundation of the entire dataset corpus. Every dataset analyzed in this project originates from one of the probes stored here, and each probe is designed to expose temporal behavior in a different modality.

This folder includes the LED tunneling entropy probe, which produces tunneling noise through a physical LED junction amplified by an LM358P op‑amp. It also contains hardware entropy probes from multiple machines, atmospheric entropy capture scripts, symbolic and inverted symbolic probes, byte‑manifold probes, tunneling manifold probes, raw temporal dynamics probes, and the Temporal Thermometer 2.0 PRNG drift probe used for real‑time temporal‑geometry measurement. Several probes generate structured manifold sequences, while others produce raw entropy streams without clustering or symbolic transformation. All probe scripts are self‑contained and can be executed independently to reproduce the datasets used in the study.

Each probe is paired with a corresponding dataset in the datasets directory and with one or more analysis scripts in the analysis directory. The complete mapping between probe scripts, their output datasets, and the analysis pipeline is documented in docs/probe_dataset_pipeline_mapping.md. This ensures full reproducibility and makes it possible to trace every result in the paper back to the exact probe that generated the underlying entropy. The probes in this directory represent the full range of entropy modalities examined in the temporal‑geometry framework and serve as the starting point for all computational analysis performed in this project.
