Temporal geometry is a new framework for understanding entropy as a process that evolves over time rather than a static distribution. This repository contains the complete experimental corpus, including all probes, datasets, analysis scripts, and visualizations used to study temporal geometry across symbolic, numeric, and raw manifolds. The work demonstrates that entropy sources consistently exhibit reproducible temporal structure. Oscillation, curvature, drift hierarchy, basin formation, and attractor behavior appear across hardware entropy, atmospheric entropy, tunneling entropy, symbolic encodings, inverted encodings, PRNG drift, raw temporal dynamics, and byte, sixteen‑bit, sixty‑four‑bit, and hexagram manifolds. The full scientific paper is included in the paper directory.

The repository is organized into several major components. The probes directory contains every entropy probe used in the study, including hardware probes, the LED tunneling entropy probe, symbolic and inverted symbolic probes, byte manifold probes, tunneling manifold probes, raw temporal dynamics probes, PRNG drift probes, hexagram probes, and the quantum probe. Each probe produces one or more datasets stored in the datasets directory. These datasets cover all entropy modalities examined in the study, including hardware, atmospheric, tunneling, symbolic, inverted, PRNG, raw temporal dynamics, and multiple manifold resolutions. Metadata for each dataset is included to ensure full traceability.

The analysis directory contains the complete temporal‑geometry computational pipeline. Ninety scripts implement preprocessing, clustering, transition matrix construction, stationary distribution extraction, drift hierarchy measurement, curvature extraction, basin and attractor analysis, temporal flow mapping, manifold comparison, resolution invariance testing, oscillation detection, and raw temporal dynamics analysis. These scripts reproduce every figure, table, and result presented in the paper. The visualizations directory contains all generated figures, including oscillation plots, curvature plots, basin diagrams, attractor strength plots, manifold comparison figures, raw temporal dynamics plots, and TT20 drift visualizations.

A detailed mapping of every probe script, the dataset it produces, and the analysis scripts that consume it is provided in docs/probe_dataset_pipeline_mapping.md. This mapping ensures complete reproducibility and makes it possible to trace every result in the paper back to its originating probe and dataset. The repository is designed so that any researcher can reproduce the full temporal‑geometry analysis by cloning the repository, installing Python 3.10 or later, installing the required scientific libraries, running any probe to generate entropy, and executing the corresponding analysis scripts. The results produced by the pipeline match the visualizations included in the visualizations directory.

This repository contains everything required for full scientific reproducibility: all probes, all datasets, all analysis scripts, all figures, all tables, the complete pipeline mapping, and the full text of the paper.
