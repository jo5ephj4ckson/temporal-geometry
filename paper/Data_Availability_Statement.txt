All entropy datasets used in this study are publicly available through Zenodo and are permanently archived under the DOI listed in the main repository README. The dataset collection includes hardware‑generated entropy streams, LED tunneling entropy recordings, atmospheric entropy captures, symbolic and inverted symbolic manifold sequences, PRNG drift logs from the TT20 Android probe, byte‑manifold encodings, tunneling‑manifold encodings, and raw temporal‑dynamics streams at multiple resolutions. These files are stored on Zenodo due to GitHub’s file‑size limitations, but the filenames and directory structure in the Zenodo archive match those expected by the analysis scripts in this repository. All analysis code, probe scripts, and visualization modules are available in the GitHub repository linked in the paper. Together, the Zenodo dataset archive and the GitHub codebase provide full reproducibility for every result presented in this study.
