The paper directory contains the complete scientific manuscript for the temporal‑geometry study, including the abstract, introduction, methodology, results, discussion, and conclusion. This folder represents the final, narrative expression of the research, where the computational pipeline, datasets, probes, and visualizations are woven together into a coherent scientific argument. While the rest of the repository provides the empirical and computational foundation of the project, the paper distills those components into a structured explanation of how temporal geometry emerges across entropy modalities and manifold resolutions.

The manuscript in this directory is directly supported by the probes, datasets, analysis scripts, and visualizations found throughout the repository. Every figure referenced in the paper originates from the visualizations directory, every dataset discussed is available through the Zenodo DOI linked in the main README, and every computational result is reproducible through the analysis scripts. The paper therefore serves as both a summary and a guide, showing how the temporal‑geometry framework reveals oscillation, curvature, drift hierarchy, basin formation, attractor behavior, and manifold‑independent temporal structure across symbolic, numeric, and raw entropy sources.

This directory also contains any supplementary text associated with the manuscript, including extended methodological notes, expanded explanations of the temporal‑geometry framework, and additional context that supports the main narrative. Together, these documents form the complete written record of the study and provide reviewers and researchers with a clear understanding of how the project was conducted, how the results were obtained, and how temporal geometry can be reproduced or extended in future work.
