The analysis directory contains the full computational pipeline used to extract temporal geometry from every entropy dataset in the project. This is the core of the repository: the scripts here transform raw entropy streams into structured manifolds, compute transition behavior, measure drift and curvature, identify basins and attractors, and generate the visualizations that appear in the paper. Each script is designed to operate independently on its corresponding dataset, but together they form a unified pipeline capable of revealing temporal structure across symbolic, numeric, and raw manifolds.

The analysis workflow begins with preprocessing, where entropy values are normalized, aligned, and prepared for manifold encoding. From there, clustering modules convert continuous entropy streams into discrete symbolic or numeric states at multiple resolutions, allowing the temporal‑geometry framework to evaluate behavior consistently across different values of k. Transition‑matrix scripts compute the movement of entropy through each manifold, while stationary‑distribution modules extract long‑term equilibrium behavior. Drift‑analysis scripts measure temporal change using resolution‑invariant metrics, and curvature modules quantify how entropy flow bends within the manifold. Basin and attractor scripts identify stable and unstable regions of the manifold, and flow‑mapping modules generate the directional movement diagrams used throughout the paper.

Every figure in the visualizations directory is produced by the scripts stored here, and every result in the paper can be traced back to a specific analysis module. The relationship between probes, datasets, and analysis scripts is documented in docs/probe_dataset_pipeline_mapping.md, ensuring complete reproducibility. Researchers can run any script in this directory to reproduce the corresponding portion of the temporal‑geometry study, provided they have downloaded the datasets from Zenodo using the DOI referenced in the main repository README.

The analysis directory represents the computational heart of the temporal‑geometry framework. It contains the full set of tools required to demonstrate oscillation, curvature, drift hierarchy, basin formation, attractor behavior, and manifold‑independent temporal structure across all entropy modalities examined in the study. Every result presented in the paper originates from the scripts stored here, making this folder essential for understanding and reproducing the temporal‑geometry pipeline.
